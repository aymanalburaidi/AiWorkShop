# ورشة عمل: الذكاء الاصطناعي في خدمة المعلم والمعلمة

عرض تقديمي تفاعلي (للشاشة) وصفحة مشاركة للجوال، منشوران على GitHub Pages.

- العرض: https://aymanalburaidi.github.io/AiWorkShop/
- صفحة المتدربات (الجوال): https://go.yafea.org.sa/VKVV (رابط مختصر يحوّل إلى https://aymanalburaidi.github.io/AiWorkShop/join/)

الرابط المكتوب على شاشة العرض هو المختصر (`joinShortUrl` في `config.json`)، ورمز QR يفتح الرابط المباشر.

## تعديل النصوص

كل نصوص العرض وصفحة الجوال في مجلد `content/`، ملف لكل شريحة. افتح الملف، عدّل النص تحت العنوان `## ...` المطلوب، واحفظ.

- `**نص**` خط أثقل.
- `` `نص` `` يُعرض من اليسار إلى اليمين (للمعادلات والرموز الإنجليزية).
- `==نص==` لون التدرج.
- القوائم: كل عنصر في سطر يبدأ بـ `- `، والأجزاء يفصلها `|`.
- لا تغيّر أسماء الحقول بعد `## `؛ البناء يتوقف ويذكر الحقل الناقص.

الأيقونات المتاحة: `clock` `layers` `chart` `users` `target` `calendar` `spark` `shield` `lock` `search` `book` `pen` `msg` `refresh` `clipboard` `copy` `check` `flask` `sigma` `feather` `bulb` `flag` `alert` `arrow` `user` `award` `qr` `school` `mic` `vote` `chip` `phone` `send`.

## البناء والنشر

```bash
pnpm run deploy
```

أو انقر مرتين على `publish.cmd`. الأمر يبني `docs/` من `content/` ثم يرفعه إلى GitHub، ويظهر التحديث خلال دقيقة أو دقيقتين.

للمعاينة دون نشر: `pnpm run build` ثم افتح `docs/index.html`.

## أثناء ورشة العمل

- افتح العرض على الحاسب **مرة واحدة** بالرابط الذي يحمل مفتاح المقدّم: `…/AiWorkShop/?k=المفتاح` (المفتاح في `secrets/presenter-key.txt`، ولا يُرفع إلى GitHub). يحفظه المتصفح ويحذفه من شريط العنوان.
- بمفتاح المقدّم تتغير شاشة الجوالات تلقائيًا حسب الشريحة: الاستطلاع يفتح التصويت، وسحابة الكلمات تفتح حقل "كلمة واحدة"، والنشاط يفتح صندوق المشاركة، وتحدّي الإبداع وجدار الإبداعات يفتحان رفع الصورة والرابط. ويظهر زر إخفاء على كل مشاركة في الجدار.
- تطلب صفحة الجوال الاسم الثلاثي والمدرسة مرة واحدة وتحفظهما في الجوال. يظهر الاسم بلون مدرسته مع كل مشاركة وفي لوحة المتدربات، وتعرض اللوحة مجموع مشاركات كل مدرسة. المدارس وألوانها في `content/02-partners.md`.
- اضغط أي بطاقة في جدار الإبداعات لعرضها كاملة (للنتائج الطويلة والصور)، و`Esc` للإغلاق.
- مفاتيح لوحة المفاتيح: الأسهم للتنقل، `L` لوحة المتدربات وعدد مشاركاتهن، `N` ملاحظات الشريحة مختصرة على شاشة العرض، `F` ملء الشاشة، `K` إدخال مفتاح المقدّم، `Shift+R` تصفير الغرفة بعد البروفة (بتأكيد، ويعيد جوالات المتدربات إلى البداية).
- النقطة الخضراء أسفل العرض تعني أن الاتصال المباشر يعمل، والحلقة البنفسجية حولها تعني أن وضع المقدّم مفعّل.

## صفحة ملاحظات المقدّم

`…/AiWorkShop/notes/` صفحة مستقلة تُفتح في شاشة أخرى أو في الجوال، ومقفلة بكلمة السر (مفتاح المقدّم نفسه، والرابط الجاهز في `secrets/presenter-link.txt`).

- تنتقل مع شرائح العرض تلقائيًا: كل انتقال في العرض يفتح ملاحظات شريحته.
- ملاحظات الشريحة تظهر واحدة بعد أخرى بترتيبها، والمقدّم يُظهر التالية بزر "الملاحظة التالية" أو المسافة أو السهم السفلي. السهم العلوي يعيد السابقة، والضغط على ملاحظة سابقة يعود إليها.
- لكل ملاحظة نوع بلون: قل، نفّذ، اسأل، انتبه، انتقل. بعد آخر ملاحظة يظهر عنوان الشريحة التالية.
- في الأعلى: الباقي من مدة الشريحة، والوقت المنقضي، والتقدم أو التأخر عن الخطة.
- السهمان الأيمن والأيسر (وزرّا "الشريحة") يحرّكان العرض نفسه عن بُعد عند الحاجة.

تعديل الملاحظات:

- ملاحظات كل شريحة تحت `## notes` في ملفها داخل `content/`، سطر لكل ملاحظة: `- النوع | النص`. الأنواع: `say` `do` `ask` `watch` `go`، وتسمياتها في `content/21-presenter-page.md`.
- مدة كل شريحة في `content/21-presenter-page.md`.
- القفل يمنع فتح الصفحة بالرابط، لكن المستودع عام ونصوص الملاحظات ظاهرة في ملفاته.

## بعد ورشة العمل

```bash
pnpm run export
```

يصدّر تقريرًا قابلًا للطباعة (`report.html`) مع ملفات CSV والصور إلى `exports/` (لا يُرفع إلى GitHub). وبعد التأكد من التقرير: `pnpm run export -- --delete` لحذف البيانات من قاعدة البيانات. الصور تُحذف من لوحة Supabase.

## البيانات

المشاركات والتصويت وأسماء المتدربات في Supabase (مشروع QProjects)، في جداول تبدأ بـ `aiws_` فقط، والصور في المخزن `aiws-uploads`. الغرفة الحالية: `hs7-ai` (من `config.json`).
