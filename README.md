# ورشة عمل: الذكاء الاصطناعي في خدمة المعلم والمعلمة

عرض تقديمي تفاعلي (للشاشة) وصفحة مشاركة للجوال، منشوران على GitHub Pages.

- العرض: https://aymanalburaidi.github.io/AiWorkShop/
- صفحة المتدربات (الجوال): https://aymanalburaidi.github.io/AiWorkShop/join/

## تعديل النصوص

كل نصوص العرض وصفحة الجوال في مجلد `content/`، ملف لكل شريحة. افتح الملف، عدّل النص تحت العنوان `## ...` المطلوب، واحفظ.

- `**نص**` خط أثقل.
- `` `نص` `` يُعرض من اليسار إلى اليمين (للمعادلات والرموز الإنجليزية).
- `==نص==` لون التدرج.
- القوائم: كل عنصر في سطر يبدأ بـ `- `، والأجزاء يفصلها `|`.
- لا تغيّر أسماء الحقول بعد `## `؛ البناء يتوقف ويذكر الحقل الناقص.

الأيقونات المتاحة: `clock` `layers` `chart` `users` `target` `calendar` `spark` `shield` `lock` `search` `book` `pen` `msg` `refresh` `clipboard` `copy` `check` `flask` `sigma` `feather` `bulb` `flag` `alert` `arrow` `user` `award` `qr` `school` `mic` `vote` `chip` `phone` `send`.

## البناء والنشر

```bash
pnpm run deploy
```

أو انقر مرتين على `publish.cmd`. الأمر يبني `docs/` من `content/` ثم يرفعه إلى GitHub، ويظهر التحديث خلال دقيقة أو دقيقتين.

للمعاينة دون نشر: `pnpm run build` ثم افتح `docs/index.html`.

## أثناء ورشة العمل

- افتح العرض على الحاسب **مرة واحدة** بالرابط الذي يحمل مفتاح المقدّم: `…/AiWorkShop/?k=المفتاح` (المفتاح في `secrets/presenter-key.txt`، ولا يُرفع إلى GitHub). يحفظه المتصفح ويحذفه من شريط العنوان.
- بمفتاح المقدّم: شرائح الاستطلاع تفتح التصويت على الجوالات تلقائيًا، وشرائح النشاط والجدار تفتح صندوق المشاركة، ويظهر زر إخفاء على كل مشاركة في الجدار.
- مفاتيح لوحة المفاتيح: الأسهم للتنقل، `N` ملاحظات المقدّم، `F` ملء الشاشة، `K` إدخال مفتاح المقدّم.
- النقطة الخضراء أسفل العرض تعني أن الاتصال المباشر يعمل، والحلقة البنفسجية حولها تعني أن وضع المقدّم مفعّل.

## البيانات
